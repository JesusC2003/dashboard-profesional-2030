# Dashboard de Proyecto Profesional 2030

Dashboard interactivo de planificación profesional desarrollado como proyecto académico para la asignatura **Fundamentos de Administración** — Universidad Popular del Cesar, Valledupar (2026).

## Vista general

El dashboard reúne en una sola página los elementos clave del proyecto profesional al horizonte 2030:

- **Perfil Profesional** — resumen de enfoque, áreas de interés y stack tecnológico
- **Diagnóstico de Competencias** — gráfico de radar interactivo dibujado en Canvas
- **Matriz DOFA** — cuadrantes con hover interactivo que resalta el cruce estratégico correspondiente
- **Cruce Estratégico** — estrategias FO, DO, FA y DA
- **Portafolio de Proyectos** — CRUD con filtros por categoría y persistencia en localStorage
- **Plan de Acción (Roadmap)** — hitos a 6 meses, 1, 3 y 5 años con estados clicables y barra de progreso
- **Reflexión Estratégica** — síntesis personal del plan

## Tecnologías

HTML5 · CSS3 (Custom Properties) · JavaScript vanilla · Canvas API

Sin frameworks ni dependencias externas.
